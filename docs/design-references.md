# 참고 앱 조사

방향을 정하기 위해 날씨·교통 분야에서 잘 만든 앱의 공개 화면을 살펴보고, 햇빛 좌석에 가져올 것과 피할 것을 정리했다. 화면을 복제하지 않고 원칙만 가져온다.

| 앱 | 가져올 것 | 피할 것 |
|---|---|---|
| Google 날씨(Pixel) | 첫 화면에 결론 한 줄과 큰 숫자. 시간 흐름을 가로 막대로 보여 주는 방식 | 배경 일러스트가 정보를 가리는 장면 |
| Apple 날씨 | 시간대별 값을 한 줄 타임라인으로 압축. 카드마다 제목 한 단어로 위계 정리 | 반투명 카드 위 흐린 회색 글자(햇빛 아래 읽기 어려움) |
| Citymapper | 구간(leg)마다 수단 아이콘·노선·시간을 한 줄로. 결론("이 칸에 타세요")을 행동 언어로 | 정보 밀도가 높아 처음 보는 사람에게 복잡함 |
| Transit | 큰 글자와 높은 대비. 지금 해야 할 일 하나를 화면 맨 위에 | 노선 색 위주 구분(색만으로 구분) |
| 카카오맵·네이버 지도 | 한국어 지명·노선 표기 관습, 검색 → 후보 → 상세 흐름. 범주+개수 탭, 현재 정렬 메뉴, 소요시간 먼저·시간 비례 막대·연결 승하차 타임라인, 후보 탭 후 별도 지도+상세 상태(#97 실기기 비교) | 브랜드 파랑·로고 복제, 공급하지 않는 실시간 정보 흉내. 좌석 결론은 이 앱의 중심으로 유지 |

## 정리한 원칙

1. **결론 먼저.** 결과 화면 맨 위에 "왼쪽 창가에 앉으세요" 같은 행동 문장과 근거 숫자 두 개(그늘·햇빛 시간)를 둔다.
2. **시간은 가로 막대로.** 좌·우 햇빛을 구간 진행에 따라 두 줄 막대로 보여 준다. 막대 옆에 항상 글자 라벨(왼쪽·오른쪽, 햇빛·그늘)을 붙인다.
3. **밖에서 읽힌다.** 정보는 불투명한 면에 진한 글자로. 보조 글자도 회색을 너무 연하게 쓰지 않는다.
4. **한 화면 한 행동.** 화면(또는 열린 시트)마다 채움 주 행동 버튼은 하나다. 채움은 중립 잉크색이며 해 색은 버튼에 쓰지 않는다(`DESIGN.md` 2.3, 13).
5. **해와 그늘이 곧 브랜드.** 해(호박색)와 그늘(짙은 남색) 두 색을 의미 색으로만 쓰고 장식 색으로 남발하지 않는다.
