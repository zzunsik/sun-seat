# 지하철 지상 구간 데이터 (#14)

수집일: 2026-11-16. 앱은 `app/src/main/resources/subway_ground.csv`를 네트워크 없이 읽는다. 공개 CSV에서 노선·역명·판정만 추출했으며, 카카오 응답은 저장하지 않았다.

| 출처 | 자료 기준 | 판정 |
|---|---|---|
| [서울교통공사 역사심도정보](https://data.seoul.go.kr/dataList/OA-13305/F/1/datasetView.do), 20241104 파일 | 2024-03-31 | 층수가 지상·고가이면 ABOVE, B로 시작하면 BELOW |
| [국가철도공단 코레일 역구조](https://www.data.go.kr/data/15041150/fileData.do) | 2026-06-30 | 승강장 행의 지상구분 |
| [국가철도공단 인천교통공사 역구조](https://www.data.go.kr/data/15041149/fileData.do) | 2026-06-30 | 승강장 행의 지상구분 |
| [국가철도공단 광주1호선 역구조](https://www.data.go.kr/data/15041148/fileData.do) | 2026-06-30 | 승강장 행의 지상구분, 광주 접두어로 수도권과 분리 |

서울 심도 자료의 `형식`은 섬식·상대식이므로 지상 여부를 뜻하지 않는다. `층수`의 명시적 지상·고가 값을 사용한다. B2로 기재된 한양대 등은 음수 깊이만으로 지상이라 추정하지 않는다. 코레일 자료는 대합실·연결통로의 지상 여부로 승강장을 판단하지 않는다. 중복 출처나 승강장 행이 충돌하면 UNKNOWN이다. 사용 허락: 각 공공데이터 페이지의 이용허락범위 제한 없음.

노선+정규화된 역명으로 조회한다. 괄호 부역명, 공백, 끝의 '역'을 제거한다. 서울역과 서울은 같은 키다. 노선이 다르면 같은 역명이라도 합치지 않는다. 제공되지 않는 노선·역은 UNKNOWN이며 추천에서 제외한다. 데이터에 없는 신설역은 추측하지 않는다.

경로 응답의 전체 정차역 목록을 확인하여 **모든 역이 지상**인 탑승 구간만 추천한다. 양 끝뿐 아니라 중간 역도 확인하므로 지하역을 지나가는 긴 탑승 구간을 지상으로 잘못 판단하지 않는다. 하나라도 지하이면 지하 구간, 자료가 부족하면 지상 여부 미확인으로 표시한다. 지상역 사이 터널·차량 차광까지 판별하는 선로 데이터는 아니며, 혼합 탑승 구간을 역 사이로 나누는 정밀화는 범위 밖이다. 제외 구간은 햇빛·그늘 합계에서 빠지고 이동 시각은 유지한다.

## 갱신

위 페이지에서 CSV 4개를 다운로드한 뒤 실행한다. 원본은 저장소에 넣을 필요가 없다.

```bash
python3 scripts/import_subway_ground.py 서울심도.csv 코레일.csv 인천.csv 광주.csv app/src/main/resources/subway_ground.csv
./gradlew assembleDebug lint test
```

UTF-8/CP949 입력을 지원한다. 최신 자료의 열 이름, 승강장 분류, 노선명, 충돌 건수를 검토하고 기준일을 함께 수정한다. `SubwayGroundDataTest`는 환승역·누락역·경로 제외·시각 보존을 검증한다. 실제 경로(예: 2호선 성수→건대입구→구의)의 결과 화면은 기기와 API 키가 필요하다.
