## 기기 확인과 남은 게이트

초기 디버그 APK를 Galaxy S25+에 설치하고 Filament의 실제 3D 출력까지 확인했다.
처음 검은 화면이 나오던 원인은 effect 키와 늦게 읽는 renderer 참조의 불일치였다.
renderer를 키 평가 전에 캡처해 즉시 dispose되던 문제를 수정했다.

독립 디자인 리뷰에서 첫 화면의 좌석/결론 가시성, 차체 가림, 선택 표시,
색 출력과 해 형태가 미흡하다는 판정을 받아 다음을 수정했다.

- 좌석과 직사광 요약을 장면 앞으로 이동, 지도/패널 1:4, 높은 기본 시점.
- 연속 중립 선택 프레임, 좌석 직접 선택 목록과 선택 시맨틱.
- 구형 태양과 입사 화살표, 출력 색 경로 수정, 차체의 약한 밝기 보완.
- 현재 시각의 태양과 방향 문구 일치, 광선 교차의 중첩 목록 할당 제거,
  정지 상태 dirty 기반 렌더링, 60Hz에서도 약 30fps가 가능한 33ms 재생 간격.

**무선 디버깅 연결이 끊겨 수정본 GPU 재검증은 대기 중이다.**
다음이 끝나기 전 ready/merge로 전환하지 않는다.

- 실제 지도 + 버스/광역버스/지하철/택시/자가용의 새 GPU 캡처.
- 전체/내부 시점, 좌석 변경, 낮은 앞/뒤/옆 해, 높은 해, 야간/지하/미상 상태.
- 재생/정지/배속/탐색, 회전·백그라운드 복귀·재진입 반복.
- 기기 프레임 시간/메모리/탐색 반응과 발열 측정, 릴리스에서 자산 로드 확인.
- 새 캡처를 사용한 독립 디자인 재리뷰 통과.

순수 JVM 기하+메시 생성 5회 측정(CAR 약44ms, BUS 약60ms, SUBWAY 약23ms)은
테스트 JVM의 참고값일 뿐 기기의 FPS/발열/탐색 지연을 증명하지 않는다.
