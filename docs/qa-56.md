## 독립 리뷰 반영

- 위 지도는 이동·시간·진행률·태양 방향/고도 개요, 아래 3D는 좌석 상세.
- 세로 2:3, 가로 좌우 배치. 지도는 자신의 영역 밖으로 그리지 않는다.
- 선택 좌석과 요약을 장면 앞에 표시하고, 자리 선택/시점 조작을 노출한다.
- 기본 카메라는 앞·우측. 전체 보기만 가까운 차체를 절개하고 CPU 차폐는 유지한다.
- 좌석·헤드레스트·대시보드·핸들·바퀴를 구성하고 환경광으로 구조를 구분한다.
- 큰 3D 해 구체를 제거하고 위 지도에 해 방향을 표시한다.
- 광선은 검증된 실제 창 개구부→좌석 선만 표시한다. 서로 다른 입사 표본 사이의
  검증되지 않은 공간을 채우던 ribbon은 제거했다. 투명 vertex RGB는 alpha와 선곱한다.
- 지도 스타일 변경의 invalidate 누락을 수정했다.

## 성능 측정과 제한

비녹화 재생 20초의 gfxinfo: 613프레임, 중앙값21ms/p90 26ms/p95 28ms/p99 31ms,
GPU 중앙값2ms/p95 4ms. 120Hz 화면의 deadline 지연은612프레임(99.84%)이다.
이는 합성 화면의 실측 30fps 보장이 아니며 고주사율 프레임 페이싱 개선 여지가 남는다.
Filament 제출은 약30Hz로 제한하고 dirty 상태만 렌더하며 기하/태양 갱신도 공통
재생 주기에 맞춘다. 비녹화 측정의 p99는33ms 이내였지만 장시간 성능 보장은 아니다.

메모리 PSS의 서로 다른 장면 측정은406→636MiB여서 이 둘만으로 누수 유무를
판정하지 않는다. 동일 장면 재진입 반복값은 아래에 별도로 기록한다.
