# 햇빛 좌석 요구사항

> 이 문서는 GitHub 이슈 #1~#18의 범위와 완료 기준을 바탕으로 정리했다. 이슈와 다르면 이슈를 기준으로 고치고 이 문서도 함께 갱신한다.

## 1. 목적

버스·지하철·자가용으로 이동할 때 햇빛을 피하거나(기본) 받을 수 있는 좌석을 구간별로 알려 준다. 개인용 앱이며 스토어에 올리지 않고 APK로 설치한다(#17).

## 2. 사용 흐름

1. **입력**(#11): 출발지(현재 위치 또는 장소 검색), 목적지(장소 검색), 수단(대중교통/자가용), 출발 시각(지금 또는 지정), 햇빛 피하기/받기
2. **경로 후보**(#12): 대중교통은 후보 목록에서 탈 경로를 고른다. 자가용은 경로가 하나면 바로 결과로 간다
3. **결과**(#13): 탑승 구간별 추천 좌석, 좌·우 노출 비율, 좌·우 타임라인
4. **설정**(#15): 지하철 기본 선호, 기본 모드
5. **최근 검색**(#16): 검색어와 수단만 저장

## 3. 추천 규칙

### 3.1 공통
- 태양 방위각·고도는 기기 안에서 오프라인으로 계산한다(#3)
- 경로를 선분으로 나눠 선분마다 진행 방향과 통과 시각을 구하고 좌·우 노출을 합산한다(#4)
- 해가 진 뒤에는 추천하지 않는다. 도보 구간은 추천에서 뺀다

### 3.2 버스·자가용(#5)
- 노출이 적은 쪽을 추천한다. 햇빛 받기 모드에서는 반대
- 좌·우 차이가 15%p 미만이면 "차이 없음"
- 버스는 "진행 방향 왼쪽/오른쪽", 자가용은 동승자 좌석(조수석, 뒷좌석 좌·우)으로 표현
- 운전자 눈부심 구간: 태양이 진행 방향 ±20° 안이고 고도 15° 이하인 구간

### 3.3 지하철(#6, #14)
- 좌석이 옆을 보므로 두 벤치의 노출을 모두 보여 준다
- 해 쪽 벤치는 등 직사, 반대쪽 벤치는 해가 낮을 때 정면 직사
- 선호: 등 뒤 햇빛 피하기(기본), 정면 햇빛 피하기, 총 노출 최소
- 지하 구간은 추천에서 빼고 "지하 구간"으로 표시한다. 지상 여부는 공공데이터를 앱에 내장해 판정한다

## 4. 외부 서비스와 제약

### 4.1 장소 검색
- 카카오 로컬 키워드 검색. 검색 응답(장소·좌표)은 저장·재사용하지 않는다

### 4.2 경로
- 대중교통: 카카오맵 대중교통 경로 조회(`/v2/routing/publictraffic`, 일 1,000건 무료)
  - 출발 시각을 지정할 수 없어 호출 시점 기준 경로를 쓴다
  - 지하철 단계의 좌표 제공 여부, 도시 간(열차·고속버스) 경로 제공 여부는 #8 첫 호출로 확정해 여기에 기록한다
- 자가용: 카카오모빌리티 자동차 길찾기(일 10,000건 무료). 경로 결과는 저장하지 않는다

### 4.3 API 키
- `KAKAO_REST_API_KEY`는 `local.properties`에만 두고 커밋하지 않는다. CI는 빈 키로 빌드한다

## 5. 품질 기준
- 색에만 의존하지 않고 좌·우를 글자로도 구분한다
- 밖에서 햇빛 아래 보는 앱이므로 대비를 우선한다
- 화면은 `docs/DESIGN.md`(#18)를 따르고 스크린샷·접근성 검사와 독립 디자인 리뷰를 거친다
